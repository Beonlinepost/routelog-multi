# RouteLog

Voice-driven postal route app for postmen.

- `index.html` — postman app (sign in, routes, Sorting / Delivery / Parcel, voice search)
- `admin.html` — admin panel (routes, Excel import, users, learned mappings, field testing, settings)
- `new-route-template.xlsx` — template for loading a new route

Data lives in Supabase behind logins and row-level security. No route data is stored in this repository.
